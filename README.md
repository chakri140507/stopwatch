# ⏱️ Stopwatch

A simple and interactive stopwatch web application built using HTML, CSS, and JavaScript.

## 🚀 Features

- Start the stopwatch
- Pause the stopwatch
- Reset the stopwatch
- Displays elapsed time
- Simple and user-friendly interface
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
